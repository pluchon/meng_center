# 萌部落社区

日漫萌系、水色主题的多用户社区：发帖、私信、成长、AI 萌萌、轻度抽奖。

## 目录

```
meng_center/
├── docs/            文档
├── deploy/          Docker 中间件、Nacos 配置及启动脚本
├── java_backend/    Java 后端（Spring Boot 4 微服务）
├── vue_front/       两个独立 Vue 3 前端
└── verification/    隔离联调、压测和浏览器验证
```

## 文档

- [架构设计](docs/architecture.md)：定位、技术栈、模块结构、服务划分、防耦合规则、范围台账

- [内容域](docs/content.md)：帖子、评论、配图的接口、数据、规则和验收点，主页、详情、发帖页的拆分
- [成长域](docs/growth.md)：签到、经验、等级的接口、数据、规则和验收点

- [AI 域](docs/ai.md)：萌萌以外的 AI：帖子理解、推荐、相关帖子、语义搜索、发帖页 AI 入口、成长总结、审核
- [前端规范](docs/frontend.md)：项目划分、目录、三文件拆分、不硬编码的做法、检查工具

- [验证](verification/README.md)：后端测试、隔离联调、压测和浏览器脚本
- [仓库卫生规则](AGENTS.md)：什么能进仓库、干完活要收拾什么

已实现主页、发帖与详情评论、搜索结果和创作中心，以及喜欢、收藏、配图和 IP 属地。成长域包含签到、经验、等级及事件同步，成长中心提供等级之路、月签到日历、今日任务、经验明细与统计。消息中心提供私信、评论、喜欢和系统四个标签页，支持鉴权图片、已读回执、在线状态和实时未读数。

认证模块已实现注册申请、管理员审核、多会话登录、重新申请、改密和找回密码。正式协议与短信配置仍待运营者提供，当前本地默认关闭注册提交和短信发送，见[环境、密钥与约定](docs/setup.md)第 4 节。
