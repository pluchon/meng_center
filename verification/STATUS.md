# 第一阶段验收记录

日期：2026-10-09。按 docs/kickoff.md 实现注册申请、审核、登录、重新申请与改密。第一阶段代码已落地；短信实发和正式协议发布仍待外部配置，不能算完成全部实发验收。

## 已完成与实测

- Docker Compose 项目 meng_center：MySQL、Redis、RabbitMQ、Nacos 四个容器 healthy，绑定本机无冲突端口，凭据来自用户环境变量，独立数据卷保留。
- 后端按 common / api / user / gateway 分模块；user 内 Controller、Service、Mapper、Converter、Client、Config、MQ 分包。网关仅依赖 common-core，无 Servlet 或业务持久层依赖。
- Nacos 三个非可选配置导入、分层覆盖、环境变量优先和服务发现已验证。关停 Nacos 后，user 与 gateway 启动均以退出码 1 失败；Nacos 已恢复 healthy。
- Flyway V1 建 user 表；V2 追加协议同意字段，保留已执行迁移历史。管理员通过独立脚本初始化，没有邮箱和手机号，不重设已有账号密码。
- AES-256-GCM 随机 IV、独立 HMAC-SHA256 检索键、BCrypt、Redis 一次性票据与验证码、限流、多设备会话和全会话撤销已实现。
- 国内短信使用 SendSms，国际短信使用 SendMessageToGlobe；完整区号匹配避免 +886 被归到 +86。接口调整已由用户授权并同步文档。
- 两个独立 Vue 3 / JavaScript 工程，页面和组件三文件拆分，Axios 唯一入口、选项式 Pinia、懒加载路由、集中常量/文案/样式变量、四种页面状态、自托管字体和现有海报素材。
- 根目录 Postman 集合已包含第一阶段接口，不保存实际密码、验证码或 Cookie。
