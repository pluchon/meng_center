# 页面对照记录

2026-10-09，使用 Windows Microsoft Edge / Playwright，对照用户端 pages_design 中的既有设计页面。截图位于 test-output/browser，验证脚本为 browser/check.mjs。

- 桌面保留 1120px 双栏卡片、40px 圆角、左侧 52% 海报区、品牌文字、云朵与底部波浪。按用户此次要求压缩留白，控件改为 44px，海报高度自适应视口。使用仓库海报素材、本地字体和指定图标，颜色统一从样式变量引用。
- 注册保留相同视觉结构，增加文档要求的地区选择、注册理由、确认密码与协议同意。审核状态和重新申请属于业务补充，没有用旧静态图替代实际交互。
- 小屏海报改为紧凑横幅，密码与确认密码并排；低高度视口进一步压缩控件与留白。1366×768、390×844、375×667 下三个页面都无整页滚动。协议正文与申请理由分别在内部滚动。
- 对照新增 Legal.dc.html 实现顶部品牌/标签、左侧编号目录、正文阅读提示、底部进度及返回入口。正式内容仍用现有待发布说明，没有把参考中的占位条款当作已发布协议。
- 登录和注册勾选区复用组件，原截图中的复选框、同意文字和协议链接错位已修复；背景增加粒子连线，支持减少动态效果。
- 验证码弹窗已实际拖动成功；管理端采用文档要求的 Element Plus 默认样式，已验证真实分页与退出。

本次覆盖 Edge 桌面与移动视口，未进行真实手机及其他浏览器验收。像素并非逐点一致；字体渲染、业务补充内容和响应式布局允许必要差异。

第二次微调按新截图修正：标题居中且登录标题上移，两页品牌标签一致；移除背景云朵和波浪，仅保留可鼠标排斥、断线的粒子。切换按钮无可见文字，两条箭头从两侧汇合。复选框与同意文字按垂直中心对齐。协议背景新增琪露诺黄昏花园插画，并铺半透明白色遮罩；进度条延伸到按钮左侧，删除百分比文字。19 组专项检查包含这些交互和位置断言。

第三次微调将密码提示与验证码按钮置于输入框内，统一占位样式；登录勾选行保留找回密码待接入入口。协议阅读区改为整体半透明面板，去掉零散装饰块，提高背景图片可见度；标签选中背景水平滑动，正文淡入。按钮增加短暂反馈，粒子主动寻找新连接。23 组专项检查验证这些位置、样式与行为。

重置页依据 Reset.dc.html，按本次要求移除背景云朵、漂浮卡片和顶部重复登录胶囊；仅保留粒子。卡片宽度 640px，圆形头像按用户粉发猫耳参考重新绘制，保留星光眼睛与小爪子姿势。联系方式和验证码组件直接与注册页共用，密码提示置于输入框，成功后只保留返回登录入口。三个既定视口无整页溢出；粒子加入连通域 8 点、每点 3 线的硬上限以及两秒散开冷却。
